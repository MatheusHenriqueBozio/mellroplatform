# Mell.ro — case de Product Design

Case navegável da Mell.ro: gestão de imóveis, anúncio e análise de inquilinos de uma plataforma de locação com aluguel garantido.

- `index.html` — o case, com índice de navegação e o protótipo completo feito das telas originais do Figma.
- `img/` — 110 telas exportadas do Figma (WebP).
- `og.jpg` — imagem de compartilhamento.

Site estático: não tem build. No Vercel, o preset é **Other**.

Links diretos para os fluxos do protótipo:

| Link | Fluxo |
| --- | --- |
| `/#explorar-home` | Visão geral |
| `/#explorar-a` | Análise de inquilinos |
| `/#explorar-b` | Status do inquilino |
| `/#explorar-c` | Gestão de imóveis |
| `/#explorar-d` | Anunciar imóvel |
| `/#explorar-e` | Responsividade |

Telas e anotações: Matheus Bozio. Nomes e valores nas telas são exemplos.
